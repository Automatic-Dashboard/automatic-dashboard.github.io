## Why Automatic Dashboard

Home Assistant is powerful, but hard to get started with. After installing it, you face an almost empty screen; a good-looking dashboard takes hours of tweaking, cards to install and YAML to write.

Automatic Dashboard makes what people usually build by hand available to everyone: the home room by room, climate, energy, alerts and system health, on a single screen. It is aimed first at beginners, and stays useful to those with hundreds of devices.

## Why this name

It says what the project does: a dashboard that builds itself from what Home Assistant already knows, and rebuilds itself when the home changes. The symbol, a room seen from the doorway, is made of interlocking pieces, like the dashboard.

## Principles

- **Zero configuration.** What can be guessed is not a setting. Settings exist, but the dashboard must be right without them.
- **Read what Home Assistant already knows.** Areas, floors, devices, states: nothing else, and nothing is sent anywhere.
- **Home Assistant cards first.** Automatic Dashboard cards only where the native ones fall short, and never a third-party card to install.
- **A stable layout.** The living room stays in the same place every evening: sizes are set once, never by the current state.
- **Sentences for the whole family.** "Bedroom window open", not a technical identifier.
- **Beautiful on every screen.** One visual identity, light and dark, from the wall tablet to the phone.

## Who makes it

Automatic Dashboard is a community project started by **Antonin Chenavaz**, who wanted to make the dashboard he built at home easy for everyone. The code is open: anyone can report a misplaced device, translate, proofread or suggest an improvement, in English or in French.

## Help it

Automatic Dashboard sells nothing and never will: no paid features, no "pro" version, nothing to unlock.

The best way to help: install it, and [tell what goes wrong](https://github.com/Automatic-Dashboard/automatic-dashboard/issues/new/choose). Every home makes the dashboard better for everyone. A star on [GitHub](https://github.com/Automatic-Dashboard/automatic-dashboard) also helps other people find it.

## What comes next

The first version is here. Next steps: joining the official catalog of the Home Assistant Marketplace, community translations and Automatic Dashboard sections to drop into any dashboard. Everything is in the [roadmap](https://github.com/Automatic-Dashboard/automatic-dashboard/milestones), one version after another; anyone can comment or pick a topic, starting with [the easiest ones](https://github.com/Automatic-Dashboard/automatic-dashboard/issues?q=is%3Aopen+label%3A%22good+first+issue%22).
