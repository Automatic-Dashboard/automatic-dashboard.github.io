# Le site d'Automatic Dashboard

Le site d'[Automatic Dashboard](https://github.com/Automatic-Dashboard/automatic-dashboard), le tableau de bord complet pour Home Assistant qui se construit tout seul. En ligne sur [automatic-dashboard.github.io](https://automatic-dashboard.github.io) : la présentation, la démo et la documentation, en français et en anglais.

Le site ne dépose aucun cookie, ne mesure pas l'audience et ne charge aucune ressource extérieure.

## Corriger une page

Une faute, une explication peu claire, une étape qui a changé dans Home Assistant : ouvrez la page sur GitHub, touchez le crayon et proposez la modification, ou [ouvrez un ticket](https://github.com/Automatic-Dashboard/automatic-dashboard.github.io/issues/new). Le site est republié tout seul à chaque changement accepté.

| Page | En français | En anglais |
|---|---|---|
| La documentation | [src/pages/documentation.md](src/pages/documentation.md) | [src/pages/en/documentation.md](src/pages/en/documentation.md) |
| Le projet | [src/pages/projet.md](src/pages/projet.md) | [src/pages/en/projet.md](src/pages/en/projet.md) |
| L'accueil et la démo | [src/i18n/textes.ts](src/i18n/textes.ts), un bloc par langue | |

Pour le tableau lui-même (un appareil mal rangé, une idée), c'est dans le [dépôt d'Automatic Dashboard](https://github.com/Automatic-Dashboard/automatic-dashboard/issues/new/choose).
